# *Star Trek: Armada* Compatibility Wrapper

A compatibility wrapper for the original [Star Trek: Armada](https://wikipedia.org/wiki/Star_Trek%3A_Armada) on modern versions of Windows.
ArmadaWrapper is intended to be used alongside [Dege's dgVoodoo 2 Graphics Wrapper](https://www.dege.freeweb.hu/dgVoodoo2/).
